# 발판 — 제주 로컬·공공 공간을 사람들이 다시 찾게 만들기

> 만든 날 2026-09-20 · 재료 3건 · 카드 3장 · 확인 필요 5건
> 주제: 제주 로컬·공공 공간을 사람들이 다시 찾게 만들기 (**추정** — 지난 프로젝트 기록에서 뽑았다. 1번 안건에서 확정할 것)
> 이 예시는 한 대학생 광고 동아리의 1기 프로젝트 기록(2025)으로 만들었다. 팀원 이름은 뺐다(원칙 4). 지난 기록을 재료로 쓸 때 「확인 필요」를 어디에 어떻게 남기는지, 씨앗을 어디서 멈추는지를 보여 주려는 예시다.

## 2. 사례 카드

### 카드 1 — 한라생태숲 브랜딩: 장소를 나이테 하나로

| | |
|---|---|
| 출처 | 1기 프로젝트 기록 §3-2 · 성과공유회 자료 p.4 · (링크 생략) · 2025-05 ~ 07 |
| 무엇을 했나 | 제주 공공디자인 공모전에 한라생태숲 로고·시설물·굿즈 디자인을 두 팀이 출품했다 — A안 「나이테 안에 제주 지형」, B안 「'한라' 글자를 선의 조화로」 |
| 눈에 띈 점 | 장소의 정체성(「제주 생태의 중심」)을 자연 상징 하나로 압축하고, 로고 → 시설물(「나이테 위에 누운 쉼」, QR 체험 프로그램) → 굿즈(머그컵·에코백)로 넓혔다. 8주, 온라인 회의 8회로 첫 공모전을 완주했지만 수상은 못 했다 |
| 우리 과제와의 접점 | 공간의 정체성을 「상징 하나 → 체험」으로 잇는 구조. 다만 왜 뽑히지 않았는지는 모른다 |
| 태그 | 디자인 · 강연/공모전 |
| 확인 필요 | ① 당시 참고한 공공디자인 사례 목록(기록에 없음) ② 공모전 심사 결과·수상작(주최 공고) |

### 카드 2 — 제주 청년몰 활성화 제안: 문제는 공간이 아니라 '발견되지 않음'

| | |
|---|---|
| 출처 | 1기 프로젝트 기록 §3-3 · 활동 일정표 이미지 · 2025-07-15 ~ 08-27 |
| 무엇을 했나 | 「제주에서 우리가 직접 풀어 보고 싶은 문제는?」에서 침체된 청년몰을 골라 현장 답사(7/21) 뒤 3팀이 활성화 기획안을 만들고, 8/27 네트워킹에서 청년몰 관계자 앞에서 발표했다 |
| 눈에 띈 점 | 답사에서 장점(넓고 쾌적, 자유 입장)과 단점(지하 구조라 찾기 어려움, 콘텐츠·홍보 부족)이 갈렸다 — 공간 자체보다 **찾아오지 못하는 것**이 문제였다. 제안은 운영에 반영되지 못했고, 기록은 「공공의 가치와 시장 요구 사이 간극」을 배웠다고 적는다 |
| 우리 과제와의 접점 | 현장 답사가 문제 정의를 바꿨다는 것 자체가 재료다. 제안이 채택되지 않은 이유가 다음 프로젝트의 출발점이 될 수 있다 |
| 태그 | 마케팅 · 로컬·공간(팀 추가 태그) |
| 확인 필요 | ③ 기획안 3건의 핵심 제안(PPT 원본을 열어야 한다) ④ 청년몰의 지금(2026) 상태 |

### 카드 3 — 제주 버스 완벽 가이드 숏츠: 공공 정보를 콘텐츠로

| | |
|---|---|
| 출처 | 1기 프로젝트 기록 §3-4 · (링크 생략) · 2025-08-15 |
| 무엇을 했나 | 제주도·관공서와 협업해 버스 노선·환승 정보를 1분 안팎의 숏츠로 만들었다 |
| 눈에 띈 점 | '안내문'으로 남을 공공 정보를 '콘텐츠' 포맷으로 옮겼다. 접근성 문제를 디자인이 아니라 **포맷 선택**으로 풀었다 |
| 우리 과제와의 접점 | 공간을 찾게 만드는 일에는 「가는 법」까지 들어간다 — 카드 2의 「찾기 어려움」과 바로 닿는다 |
| 태그 | 트렌드 · 로컬·공간(팀 추가 태그) |
| 확인 필요 | ⑤ 링크가 살아 있는지, 조회수·반응(기록에 없음) |

## 4. 문제 정의 초안

| 안 | 누구의 | 어떤 문제를 | 왜 지금 | 근거 카드 |
|---|---|---|---|---|
| A | 제주에 사는·찾는 20대 | 청년몰처럼 '있는데 못 찾는' 로컬 공간을 만나지 못한다 | 2025년 답사에서 확인된 문제가 그대로일 가능성이 높다(④ 확인 뒤) | 2 · 3 |
