# 관리 파일 내부 구조

2026-09 기준. 사용자가 Excel에서 직접 구조를 바꿀 수 있으므로, 작업 전에 실제
파일을 읽어 아래와 다른 점이 있는지 확인하고, 다르면 실제 구조를 따른다.

## 견적서발행대장.xlsx — 시트 "견적서발행"

| 열 | 내용 | 비고 |
|---|---|---|
| A | 발행순서 (1~30, 미리 채워짐) | 건드리지 않음 |
| B | 발행일 | 날짜, yyyy-mm-dd 형식 |
| C | 견적번호 | 없는 견적서는 비움 |
| D | 대상(기업명) | 견적서의 "수신" 기준 |
| E | 견적명 | |
| F | 견적금액(공급가액, VAT별도) | 일부 행에 0이 미리 들어있을 수 있음 |
| G | 부가세 `=F*0.1` | 기존 수식 유지 |
| H | 금액합계 `=F+G` | 기존 수식 유지 |
| I | (비고 메모, 회색 글씨) | 근거·특이사항 기록용 |

- 데이터 행: 3~32. 33행 합계 `=SUM(F3:F32)` 등, 34행 예상매출 `=F33`.
- 빈 행 판정: B~E가 모두 비어 있으면 빈 행 (F의 미리 채워진 0은 무시).
- 금액 표시형식: `_-[$₩-412]* #,##0_-...` (₩ 한국 원화 서식).
- 이 파일은 외부 링크가 없으므로 openpyxl로 편집해도 되지만, 저장하면 수식
  캐시가 비므로 LibreOffice 재계산이 필요하다.

## 매출소득관리.xlsx — 시트 "매출소득관리"

2026-09 현재 열 배치 (사용자가 세금계산서 발급여부 열을 삭제한 뒤 상태):

| 열 | 내용 | 채우는 주체 |
|---|---|---|
| A | 발급번호 `=[1]견적서발행!A행` | 외부 링크 |
| B | 견적번호 `=[1]견적서발행!C행` | 외부 링크 |
| C | 대상 `=[1]견적서발행!D행` | 외부 링크 |
| D | 견적명 `=[1]견적서발행!E행` | 외부 링크 |
| E | 견적금액(VAT포함) `=[1]견적서발행!H행` | 외부 링크 |
| F | 입금일 | **사용자 직접 입력** |
| G | 입금액 `=E행` (견적금액 자동 반영, 실제 입금액이 다르면 사용자가 값으로 덮어씀) | 수식/사용자 |
| H | 인건비(알바 등) | **사용자 직접 입력** |
| I | 자재비 | **사용자 직접 입력** |
| J | 비고 | 사용자 |

- 데이터 행: 3~28 (발행대장보다 짧음: 발행순서 1~26까지만 연동).
- 요약(29~34행, 라벨은 F열): G29 합계금액
  `=SUMIFS(G3:G28,F3:F28,"<>",G3:G28,"<>")` — **입금일과 입금액이 모두 작성된
  행만 합산** (사용자 요청으로 이렇게 만든 것이니 유지할 것). G30 부가세,
  G31 매출액, G32 세금예비비, G33 최소통장유지금액, G34 소득
  `=G31-G33-H34-I34`. H34=인건비합, I34=자재비합.

### 외부 링크 동작 (핵심)

- 수식의 `[1]`은 `xl/externalLinks/_rels/externalLink1.xml.rels`의 Target이
  가리키는 파일. **같은 폴더 기준 상대경로 `견적서발행대장.xlsx`를 유지해야 한다.**
  (사용자 요청. Excel이 저장하며 절대경로 힌트를 덧붙이는 건 정상이라 놔둔다.)
- `xl/externalLinks/externalLink1.xml`의 `<sheetDataSet>`이 원본 값의 캐시다.
  원본 파일이 닫혀 있을 때 Excel/LibreOffice는 이 캐시로 계산한다.
  발행대장이 바뀌면 이 캐시를 다시 써 줘야 한다 → register_quote.py가 수행.
- openpyxl로 이 파일을 저장하면 외부 링크 캐시와 수식 캐시가 사라져
  값이 전부 0/빈칸이 된다. **절대 openpyxl로 저장하지 말 것** (읽기는 안전).

### 재계산 파이프라인 (register_quote.py가 하는 일)

1. 외부 링크 캐시(sheetDataSet)를 발행대장 현재 값으로 교체 (zip 수준)
2. 모든 수식 셀의 캐시값 `<v>` 제거 — 캐시가 남아 있으면 LibreOffice가
   재계산을 건너뛰기 때문
3. calcChain 제거 (Excel이 저장하며 남긴 것; 수식 구성이 바뀌면 무효)
4. `soffice --headless --convert-to xlsx`로 재계산 후 제자리 교체
5. LibreOffice가 링크 Target을 `../파일명`으로 바꿔 놓으므로 `견적서발행대장.xlsx`
   (파일명만)으로 복원
6. `#REF!` 등 수식 오류 검사

## 견적서 템플릿 (assets/quote_template.xlsx)

회사 견적서 양식. 공개본은 회사명·주소·사업자번호·담당자 연락처를 ○ 표시로 바꾸고
로고·직인 이미지를 자리표시 이미지로 바꾼 것이다. 실제로 쓸 때는 자기 회사 양식의
같은 칸에 맞춰 이 파일을 교체한다. 시트 "견적서"의 가변 셀:

| 셀 | 내용 |
|---|---|
| A6 | `수     신 : {대상}` |
| A8 | `견 적 일 : YYYY년 MM월 DD일` |
| E9 | 견적금액 `=I32` (캐시만 갱신) |
| I9 | `[견적번호 : 견적YYYY-JNNN]` |
| A13 | `견 적 명 : {견적명}` |
| C17~C26 | 견적내용 줄들 (최대 10줄, 남는 칸은 비움) |
| I30 | 시험성적서 발급 금액 (숫자) |
| E31/I31 | 출장비 입력칸 / `=E31` |
| I32 | 합계 `=SUM(I30:I31)` (캐시만 갱신) |
| G41 | 최종합계 `=I32` (캐시만 갱신) |

- 원본 양식의 둘째 시트(과거 견적 근거 자료)는 공개본에서 뺐다.
- xl/media에 로고·직인 이미지 3개가 있다(공개본은 자리표시 이미지). openpyxl 저장 시 유실되므로
  fill_quote.py(zip 수준 편집)만 사용한다. 생성 후 이미지 개수를 검증한다.
- 이 양식의 금액은 공급가액(VAT 별도) 기준이다.

## 견적번호 규칙

`견적YYYY-JNNN` (예: 견적2025-J014). 발행대장 C열에서 올해 연도 최대 NNN+1.
과거 견적서에는 다른 체계(FK-2018-CL00-제주도 등)도 있으니 패턴이 맞는 것만 집계.
