# 견적서 발행 자동화 (quote-issue)

새 견적서 생성 → 견적서발행대장 기입 → 매출소득관리 동기화를 한 번에 처리한다.

## 파일 위치

기준 폴더(BASE)는 다음 순서로 정한다:
1. 현재 작업 폴더에 `견적서발행대장.xlsx`가 있으면 그 폴더
2. 아니면 `C:\Users\<사용자>\Documents\Claude\견적예상매출` (설치 후 이 줄을 실제 폴더 경로로 수정해 둘 것)

BASE 안에 `견적서발행대장.xlsx`, `매출소득관리.xlsx`, `견적서\` 폴더가 있다.
두 관리 파일은 항상 같은 폴더에 함께 있어야 한다(상대경로 링크).

시작 전에 BASE에 `~$견적서발행대장.xlsx` 또는 `~$매출소득관리.xlsx` 잠금 파일이
있는지 확인하라. 있으면 사용자가 Excel로 파일을 열어 둔 것이므로, 닫아 달라고
요청한 뒤 진행한다(열려 있는 채로 덮어쓰면 사용자 편집 내용과 충돌한다).

## 왜 전용 스크립트를 써야 하는가 (중요)

- **매출소득관리.xlsx를 openpyxl로 열어 저장하면 파일이 망가진다.** 이 파일은
  발행대장을 `=[1]견적서발행!A3` 형태의 외부 링크로 참조하는데, openpyxl은
  외부 링크 캐시를 지워 버린다. 반드시 `register_quote.py`(zip 수준 수정)를 쓴다.
- **견적서 템플릿을 openpyxl로 편집하면 로고·직인 이미지가 유실된다.**
  반드시 `fill_quote.py`(zip 수준 수정)를 쓴다.
- 재계산은 LibreOffice headless가 필요하다(`C:\Program Files\LibreOffice`).
  스크립트가 알아서 처리하지만, 없으면 사용자에게 설치를 안내한다.

두 파일의 내부 구조(열 배치, 수식, 외부 링크 동작)는
[references/file-structures.md](references/file-structures.md)를 읽어라.
특히 구조가 예상과 다르거나 스크립트가 실패하면 반드시 먼저 읽을 것.

## 워크플로우 A: 새 견적서 발행 (기본)

1. **정보 수집.** 필요한 항목: 대상(수신 기업명), 견적명, 공급가액(VAT별도),
   견적내용 줄들(최대 10줄), 견적일(기본: 오늘), 출장비(기본: 0).
   사용자가 말한 것에서 최대한 뽑아내고, 대상·견적명·금액 중 빠진 것만 물어본다.
   금액이 VAT 포함인지 별도인지 애매하면 확인한다(대장의 견적금액은 공급가액 기준).

2. **견적번호 채번.** 발행대장 C열(3~32행)을 읽어 `견적YYYY-JNNN` 패턴 중
   올해 연도의 최대 NNN + 1로 정한다(예: 견적2025-J014가 최대면 → 견적2025-J015,
   올해 것이 없으면 J001). 사용자가 번호를 지정했으면 그것을 쓴다.
   발행대장 읽기는 openpyxl로 해도 안전하다(저장만 하지 않으면 됨).

3. **견적내용 줄 작성.** 임시 폴더에 UTF-8 텍스트 파일로 저장. 기존 관례:
   ```
   - 업   체   명 : ㈜대상기업
   - 구         분 : 일반 시험성적서
   - 시험 항목 1 : 항목 설명
   - 시험 항목 2 : 항목 설명
   ```
   사용자가 내역을 안 줬으면 업체명·구분 두 줄만이라도 채운다.

4. **견적서 생성.**
   ```
   python <스킬폴더>/scripts/fill_quote.py --out "BASE\견적서\견적서_대상명.xlsx" \
     --date 2026-01-15 --number "견적2026-J001" --client "㈜대상" \
     --title "OO 시스템 v1.0" --amount 5000000 --lines-file lines.txt
   ```
   파일명은 `견적서_{대상}.xlsx` (㈜/(주)와 공백 제거, 예: 견적서_아이클로.xlsx).
   같은 이름이 있으면 사용자 의도를 확인하거나 `_v2`를 붙인다.

5. **발행대장 기입 + 매출소득관리 동기화.**
   ```
   python <스킬폴더>/scripts/register_quote.py --base "BASE" \
     --date 2026-01-15 --number "견적2026-J001" --client "㈜대상" \
     --title "OO 시스템 v1.0" --amount 5000000
   ```
   스크립트가 빈 행 탐색, 부가세·합계 재계산, 매출소득관리 캐시 갱신·재계산,
   링크 상대경로 복원, 수식 오류 검사까지 수행한다.

6. **결과 보고.** 생성된 견적서 경로, 발행대장 행 번호, 공급가액/부가세/합계를
   표로 요약한다. 파일 전달 도구가 있으면 견적서 파일을 사용자에게 보낸다.

## 워크플로우 B: 이미 만든 견적서를 대장에 등록만

사용자가 견적서 파일을 직접 만들었거나 외부에서 받았을 때:
1. 해당 .xlsx를 openpyxl(data_only=True)로 **읽어서** 견적일·견적번호·수신·
   견적명·공급가액을 추출한다. 양식이 제각각이므로 셀을 찾지 말고 내용을 훑어라
   (예: "견 적 일", "수신", "합계", "VAT" 문구 주변). 공급가액인지 VAT포함인지
   문서 표기로 판단하고, VAT포함 금액만 있으면 1.1로 나눠 역산 후 비고에 남긴다.
2. 위 5번 `register_quote.py`만 실행한다.

## 워크플로우 C: 동기화만

사용자가 발행대장을 손으로 고쳤다면:
```
python <스킬폴더>/scripts/register_quote.py --base "BASE" --sync-only
```

## 결과 확인 원칙

스크립트는 성공 시 `OK:` 로 시작하는 요약을 출력하고, 수식 오류가 있으면 실패한다.
실패하면 오류 메시지를 그대로 사용자에게 숨기지 말고 원인과 함께 보고한다.
매출소득관리의 입금일·입금액·인건비·자재비 열은 사용자가 직접 쓰는 칸이므로
스크립트가 건드리지 않으며, 건드려서도 안 된다.
