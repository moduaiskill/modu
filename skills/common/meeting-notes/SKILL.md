# 회의록 정리

제공받은 기록을 참석하지 않은 사람도 이해하고 다음 행동을 확인할 수 있는 회의록으로 정리한다. 외부 도구 없이 텍스트 입력으로 수행한다.

## 입력 처리

회의 메모, 녹취 텍스트 또는 대화 기록을 사용한다. 기록이 없으면 회의 내용을 요청한다. 날짜·참석자·장소가 없어도 주어진 내용부터 정리하고 빠진 정보는 `미정`으로 표시하거나 해당 항목을 생략한다.

## 정리 기준

1. 안건별로 논의 내용을 묶고 반복을 줄인다. 제안, 반대 의견, 확정 결정을 구분한다.
2. 명시적으로 합의하거나 결정한 내용만 결정 사항으로 적는다. 빈 체크박스나 비어 있는 결정 칸을 확정으로 해석하지 않는다.
3. 후속 할 일을 행동 단위로 나눈다. 담당자·기한은 명시된 값만 적고 없으면 `미정`으로 표시한다.
4. 기록끼리 충돌하면 상충하는 내용을 함께 적고 `확인 필요`로 표시한다. 기준 날짜가 불명확한 상대 날짜는 원문 표현을 유지한다.
5. 미해결 질문과 다음 논의 항목을 따로 모은다. 원문에 없는 결론, 수치, 일정이나 참석자를 만들지 않는다.

## 출력

사용자가 제공한 양식을 우선한다. 별도 양식이 없으면 다음 구조의 한국어 Markdown으로 작성한다.

- 회의명과 기본 정보
- 안건별 논의 요약
- 결정 사항
- 후속 할 일 표 — 할 일 / 담당자 / 기한
- 미정 사항과 다음 논의

해당 내용을 찾을 수 없는 경우 `기록 없음`으로 표시한다. 결과에 영향을 주는 모호한 정보는 마지막에 확인할 질문으로 짧게 남긴다. 외부 발송이나 일정 등록은 이 스킬의 범위에 포함하지 않는다.
