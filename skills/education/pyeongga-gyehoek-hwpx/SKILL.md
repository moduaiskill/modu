# 교수·학습 및 평가계획 hwpx

평가요소 1개 = 표 1묶음(상·중·하 3행). 열: 영역 | 단원명(교수·학습 내용) | 평가 요소 | 평가 방법 | 성취기준 | 성취수준 | 평가 시기

**토큰 절약 원칙**: 자료 전체를 읽지 않는다. 묶음 파일은 내려받기만 하고(대화에 본문이 붙지 않음), 성취수준표는 필요한 코드만 `grep`한다. 웹(에듀넷) 조회는 코드가 표에 없을 때만.

## 1. 준비 (한 번에)
1. Artifact `action:"read"`, `url:"https://claude.ai/artifact/SRfQ4UEMBr7G2KRawTFqFr"`, `path:"bundle.b64.txt"`, `out_dir:"/tmp/pg"`
2. 풀기 + 필요한 성취기준만 조회(학년에 상관없이 같은 명령):
```bash
cd /tmp/pg && base64 -d bundle.b64.txt > b.zip && unzip -qo b.zip && grep -hF -e "[4수01-01]" -e "[4수01-02]" levels*.tsv
```
묶음 내용: `tpl/`(빈 양식), `make_plan.py`(생성기), 2022 개정 초등 성취기준별 성취수준표 3개
- `levels12.tsv` 1~2학년군 100개(국어·수학·바른 생활·슬기로운 생활·즐거운 생활)
- `levels34.tsv` 3~4학년군 231개(국어·사회·도덕·수학·과학·체육·음악·미술·영어)
- `levels56.tsv` 5~6학년군 277개
- 열(공통): 코드·영역·주제·성취기준·A·B·C. 사회·과학은 영역 열이 단원명, 통합교과는 영역 열이 주제(예: 우리는 누구로 살아갈까), 수학은 주제 열에 소단원(예: 다섯 자리 이상의 수)이 있다.
- 아티팩트를 못 읽으면 사용자에게 빈 양식 hwpx를 첨부받아 `unzip -q 양식.hwpx -d /tmp/pg/tpl`로 쓰고, 생성기는 같은 아티팩트의 `make_plan.py.txt`를 쓴다.
- 학교 양식이 바뀌면 새 hwpx를 `tpl`에 풀고, 생성기의 본표 `hp:tbl id`와 제목 문자열만 맞춰 고친다.

## 2. 입력
- 필수: 성취기준(코드+문장), 평가요소. 사용자가 준 문장은 글자 그대로 쓴다.
- 코드만 있으면 tsv의 성취기준 문장을 쓴다(`<탐구 활동>` 이후는 빼도 된다).
- grep 결과가 비면(표에 없는 교과·오타 코드): 코드를 사용자에게 한 번 확인한다. 코드가 맞으면 에듀넷 성취수준 자료실 `https://www.edunet.net/cmnBoard/list/57`을 WebFetch로 열어 해당 학년군·교과 자료의 미리보기에서 **그 코드의 A·B·C만** 뽑아 달라고 prompt에 적는다. 그래도 못 찾으면 3의 문체 규칙으로 직접 쓰고 답변에서 알린다.
- 학년·학기가 코드로 정해지지 않으면 한 번에 묶어 묻는다. 대답이 없으면 추정하고 답변에서 알린다.
- 단원명을 안 주면 tsv에서 가져온다(사회·과학·통합교과는 영역 열, 수학은 주제 열, 그 외는 주제 열이 있으면 그것). 없으면 성취기준 내용으로 짓고 "교과서에 맞게 고쳐 주세요"라고 알린다.
- 평가 시기를 모르면 `◯월`.

## 3. 내용 규칙 (2022 개정, 2015 개정 용어를 섞지 않는다)
**영역**
- 기본은 tsv 영역 열. 통합교과는 영역 열(주제)을 그대로 쓴다.
- 사회·과학은 영역 열이 단원이므로 영역은 과학(운동과 에너지/물질/생명/지구와 우주/과학과 사회), 사회(지리 인식/자연환경과 인간 생활/인문환경과 인간 생활/지속가능한 세계/정치/법/경제/사회·문화/역사 일반/지역사/한국사) 중에서 고른다.
- 표에 없는 코드는 가운데 번호로 정한다. 국어 01듣기·말하기 02읽기 03쓰기 04문법 05문학 06매체 / 수학 01수와 연산 02변화와 관계 03도형과 측정 04자료와 가능성 / 영어 01이해 02표현 / 도덕 01자신과의 관계 02타인과의 관계 03사회·공동체와의 관계 04자연과의 관계 / 체육 01운동 02스포츠 03표현 / 음악 01연주 02감상 03창작 / 미술 01미적 체험 02표현 03감상.

**성취수준 (상=A, 중=B, 하=C)**
- tsv의 A·B·C를 **기준으로** 쓴다. 평가요소가 성취기준 전체와 같으면 그대로, 일부만 다루면 그 부분에 맞게 줄이되 표현과 수준 구분은 원문을 따른다.
- 표·에듀넷에서 못 찾아 직접 쓸 때만:
  - A: 핵심을 정확히 수행하고 방법·이유를 **설명**하거나 **실생활·새 상황에 활용**할 수 있다.
  - B: 성취기준 문장 수준으로 **수행할 수 있다**.
  - C: **안내된 절차에 따라** / **간단한** 대상에서 / **부분적으로** 수행할 수 있다.
  - "~할 수 있다."로 끝내고 부정문은 쓰지 않는다. 수준당 1문장, 40~90자.

**단원명 칸**: `번호. 단원명` 다음 줄에 `▪ 교수·학습 내용` 1~3개("~하기").
**평가 방법**: 1~2개(서술형·논술형·구술·토의·토론·프로젝트·실험·실습·실기·관찰평가·포트폴리오·자기평가·동료평가). 과정 중심 평가를 우선한다.

## 4. 생성
`/tmp/pg/input.json`:
```json
{"grade":"5","semester":"2","subject":"수학","items":[{"area":"수와 연산","unit":"1. 자연수의 혼합 계산","contents":["내용1","내용2"],"element":"평가요소","method":"서술형\n동료평가","standard":"[6수01-01] 성취기준 문장","levels":{"상":"…","중":"…","하":"…"},"timing":"9월"}]}
```
```bash
cd /tmp/pg && python3 make_plan.py tpl input.json "<학년>학년_<학기>학기_<교과>_교수학습및평가계획.hwpx"
```
확인은 짧게: `unzip -p *.hwpx Contents/section0.xml | python3 -c "import sys,xml.dom.minidom as d;d.parseString(sys.stdin.buffer.read());print('ok')"`
