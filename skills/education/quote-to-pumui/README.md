# 견적서 → 품의 (quote-to-pumui) 안내

제작: 한민철 (모두의 AX 도구함 TF 1기). 아래는 제작자가 쓴 스킬 설명입니다.

```text
견적서 → 품의 스킬 (quote-to-pumui)
==================================================

학교 견적서 엑셀 파일을 넣으면 에듀파인 품의에 필요한 두 가지를 만들어 줍니다.


[만들어 주는 것]

1. 머릿공문(제목·본문)
   - 바로 복사해서 붙여 넣을 수 있는 짧은 공문입니다.
   - 학년도, 사업명, "첫 품목 외 n종", 총액이 자동으로 들어갑니다.

   (예시)
   제목: 2026학년도 전문적학습공동체 운영도서 구입

   1. 관련: 2026학년도 ○○초등학교 교육계획(교육과정)

   2. 2026학년도 전문적학습공동체 운영도서 구입 관련 아래와 같이 지출하겠습니다.
     가. 품목: AI 격차 외 23종
     나. 금액: 480,000원.  끝.

2. 품목내역 업로드 파일(.xls)
   - 에듀파인 품의 화면에서 일괄 업로드하는 파일입니다.
   - 열 구성: 내용 | 규격 | 단위 | 수량 | 예상단가


[진행 순서]

1. 견적서 읽기
   - .xlsx와 .xls를 모두 읽습니다.
   - "○○학교 귀중"에서 학교명을, "견적금액"에서 총액을 찾고, 품목 표를 가져옵니다.

2. 지출 목적 묻기
   - "어떤 돈을 지출하시나요?"를 한 번만 묻습니다.
     (예: 전문적학습공동체 운영도서 구입, 학급운영비 물품 구입)
   - 답을 공문 제목과 본문에 넣습니다.

3. 파일 만들기
   - 합계·소계 행과 빈 행은 빼고, 품목은 견적서 줄 그대로 옮깁니다.
   - 규격 칸이 없으면 도서는 "저자 / 출판사"로 채웁니다.
   - 단위가 없으면 도서는 "권", 나머지는 "개"로 넣습니다.

4. 검증
   - 수량×단가를 더한 값이 견적금액과 맞는지 확인합니다.
   - 다르면 두 금액을 모두 알려 드립니다.


[편리한 점]

- 시트가 여러 개면(예: 견적서/수정견적서) 합계가 견적금액과 맞는 시트를
  골라 씁니다.
- 1~2월 견적서는 전년도 학년도로 처리합니다.
- 금액이 수식으로 들어 있어도 계산된 값을 가져옵니다.


[이런 요청에 씁니다]

- "이 견적서로 품의 작성해줘"
- "품목내역 업로드 파일 만들어줘"
```
