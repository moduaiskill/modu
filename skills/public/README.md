# 공공기관

공공기관의 반복 행정 업무를 위한 스킬을 모읍니다.

공유 스킬은 [Markdown → HWPX 변환](md-to-hwpx/SKILL.md)입니다. Python 실행 환경이 필요하며 [ZIP](../../downloads/md-to-hwpx.zip)으로 받을 수 있습니다.

1주차 제작 방향은 공공 배포용 업무 스킬입니다. 기안·행정 자료 정리는 프로젝트 소개 문서에서 나온 추가 후보이며 세부 범위는 제작자가 정합니다.

스킬은 이 폴더 아래 `<스킬명>/SKILL.md`로 추가합니다. [기여 가이드](../../CONTRIBUTING.md)를 참고하세요.
