# 스킬 이름을 작성하세요

제작용 템플릿이며 설치용 스킬이 아닙니다. 안내를 실제 지침으로 교체해 `skills/<분야>/<스킬명>/SKILL.md`에 저장하세요.

## 목적과 사용자

누구의 어떤 반복 업무를 해결하며 어떤 결과물을 만드는지 작성하세요.

## 필요한 입력

필수·선택 자료를 구분하고 핵심 입력이 없을 때 무엇을 요청할지 작성하세요.

## 업무 절차

필요한 판단 기준과 순서를 작성하세요. 특정 도구가 필요하면 요구 환경과 지원하지 않을 때 가능한 방법을 설명하세요.

## 출력 형식

결과물 구조나 양식을 작성하세요. 사용자가 별도 양식을 제공했을 때의 처리도 포함하세요.

## 확인할 사항

업무에서 중요한 정확성 기준과 한계, 추측하면 안 되는 정보와 누락 정보 처리 방법을 작성하세요.
