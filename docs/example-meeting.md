# 회의록 정리 예제

동작 확인을 위한 가상 데이터이며 실제 TF 회의 기록이 아닙니다.

## 입력

```text
2026년 9월 10일, 자료 공유 페이지 회의. 참석은 민수와 지연.
공유 페이지는 9월 18일 공개하기로 확정.
민수가 소개 문구를 9월 14일까지 작성하기로 함.
검색 기능도 넣자는 의견이 있었으나 다음 회의에서 결정하기로 함.
사용 예시 캡처가 필요하다는 데 동의했고 지연이 맡기로 함. 기한은 정하지 않음.
```

## 기대 결과

- 확정 사항은 9월 18일 공개, 소개 문구 작성, 사용 예시 캡처 준비입니다.
- 소개 문구 담당자는 민수, 기한은 9월 14일입니다.
- 캡처 담당자는 지연, 기한은 `미정`입니다.
- 검색 기능 추가는 확정이 아닌 다음 회의의 논의 항목입니다.
- 원문에 없는 장소, 다음 회의 날짜, 공개 담당자를 만들지 않습니다.

사람이 결과를 확인하는 기준이며 특정 모델에서 실행 검증을 완료했다는 뜻은 아닙니다.
