Issues · Pull Request기여 가이드

스킬 제작 순서

  1. 이슈로 제안합니다

    업무, 사용자, 기존의 어려움, 기대 효과를 공유합니다.

  2. 템플릿을 복사합니다

    templates/skill-template/을 skills/<분야>/<스킬명>/에 복사하고 폴더명과 name을 같은 영문 소문자·숫자·하이픈 이름으로 바꿉니다.

  3. 지침을 채웁니다

    작성 안내를 실제 지침으로 대체합니다. 제작 규격을 참고합니다.

  4. 직접 사용해 봅니다

    가상 또는 공개 가능한 입력으로 확인합니다. 입력, 출력, 확인한 모델과 날짜, 알려진 한계를 기록하고 결과물 캡처를 첨부합니다.

  5. Pull Request를 보냅니다

    사용자·사용 근거·효용을 함께 설명합니다. 검수 상태와 실제로 확인한 환경을 구분해 기록합니다.

기수 참여자라면

GitHub가 익숙하지 않은 기수 참여자는 회의록에 안내된 카카오톡 채널로 폴더와 캡처를 전달할 수 있습니다. 최종 피드백을 거친 뒤 홈페이지에 소개합니다.

홈페이지 소개는 assets/js/catalog.js에 항목을 추가해 반영합니다. 제작 전에는 제작 후보 상태를 유지하고, 배포 파일이 준비되면 공유 상태로 바꿔 SKILL.md와 ZIP 경로, 요구 환경을 연결합니다.
