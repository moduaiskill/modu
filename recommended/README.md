| 자료 | 작성 주체 | 활용 목적 |
| --- | --- | --- |
| [Claude Code Skills](https://code.claude.com/docs/en/skills) | Anthropic | SKILL.md 구성과 Claude Code 설치 방식 |

확인일은 2026년 9월 13일입니다. 원문은 링크로 소개하며 재배포하지 않습니다. 문서의 저작권과 이용 조건은 원 작성 주체에 있습니다.

외부 스킬 추천 시 이름, 원본 URL, 작성자, 라이선스, 확인 날짜, 활용 목적과 요구 도구를 적습니다. 외부 자료에 저장소의 MIT 라이선스가 자동으로 적용되지 않습니다.
