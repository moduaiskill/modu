# 스킬로 만든 결과물

사용자가 제공한 기존 시연 자료 6종입니다. 형식과 활용 범위를 참고하기 위한 샘플로 공개합니다. 아래 결과물이 모두 이 저장소의 두 스킬만으로 만들어졌다고 단정하지 않습니다.

| 결과물 | 브라우저에서 보기 | 내려받기 |
| --- | --- | --- |
| 공공 입찰 제안서 | [HTML](01_제안서_샘플.html) | [PDF](01_제안서_샘플.pdf) |
| 발표자료 | [HTML](02_발표자료_샘플.html) | [PDF](02_발표자료_샘플.pdf) |
| 발표대본 | [HTML](03_발표대본_샘플.html) | [PDF](03_발표대본_샘플.pdf) |
| 사업 탐색 대시보드 | [HTML](04_사업탐색대시보드_샘플.html) | HTML 원본 사용 |
| 카드뉴스 | [HTML](05_카드뉴스_샘플.html) | HTML 원본 사용 |
| 견적서 | [PDF](06_견적서_샘플.pdf) | [XLSX](06_견적서_샘플.xlsx) |

샘플은 원본 내용을 보존했습니다. 기관명·사업 수치·일정은 현재의 검증된 정보나 TF 운영 성과가 아닙니다. 특히 카드뉴스의 모집 기간, Discord 운영과 인증서 안내는 과거 시연 내용이며 현재 참여 안내는 [기여 가이드](../CONTRIBUTING.md)를 따릅니다. 사업 탐색 대시보드의 공고·금액·적합도는 원문에서 가상 데이터로 안내하고 있습니다.

일부 HTML은 외부 CDN의 폰트·Chart.js·html2canvas·JSZip을 사용하므로 차트나 내보내기 기능에는 인터넷 연결이 필요할 수 있습니다. 파일 안에 포함된 기관 로고와 기타 저작물의 권리는 각 권리자에게 있습니다.
