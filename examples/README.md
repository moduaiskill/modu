`09`·`10`은 시험용 메모로 `case-to-project` 스킬을 돌린 결과를 손대지 않고 넣은 것입니다. `11`은 회사 정보·직인을 가린 공개용 양식으로 `quote-issue`의 `fill_quote.py`를 실행해 만든 견적서이며 수신처 ㈜예시기업은 가상입니다. `12`는 `vibe-spec` 스킬에 들어 있는 예시 계획(동네 반찬가게)으로 만든 계획 지도와 단계 시작 파일입니다. 강의보고서는 수강생 얼굴이 담긴 증빙사진과 서명을 가린 미리보기 이미지만 공개합니다.

`07_회의록_샘플.hwpx`는 가상 회의 데이터로 쓴 회의록 Markdown을 `skills/public/md-to-hwpx/scripts/md_to_hwpx.py`로 변환한 파일입니다. 한컴오피스에서 열어 확인합니다.

샘플은 원본 내용을 보존했습니다. 기관명·사업 수치·일정은 현재의 검증된 정보나 TF 운영 성과가 아닙니다. 특히 카드뉴스의 모집 기간, Discord 운영과 인증서 안내는 과거 시연 내용이며 현재 참여 안내는 [기여 가이드](../CONTRIBUTING.md)를 따릅니다. 사업 탐색 대시보드의 공고·금액·적합도는 원문에서 가상 데이터로 안내하고 있습니다.

일부 HTML은 외부 CDN의 폰트·Chart.js·html2canvas·JSZip을 사용하므로 차트나 내보내기 기능에는 인터넷 연결이 필요할 수 있습니다. 파일 안에 포함된 기관 로고와 기타 저작물의 권리는 각 권리자에게 있습니다.
